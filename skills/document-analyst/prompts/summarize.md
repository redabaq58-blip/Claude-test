# Document Summary Prompt Template

```
Analyze and summarize the following document:

{{document}}

Provide:
1. TL;DR (3 sentences max)
2. Document type and purpose
3. Key information (organized by category)
4. Action items (with owners/deadlines if mentioned)
5. Important dates
6. Risk flags or items requiring attention
7. Recommended next steps

Quote source text for important claims. Flag any sensitive information.
```
