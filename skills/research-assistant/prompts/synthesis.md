# Synthesis Prompt Template

Use this after gathering raw research to synthesize into a final output:

```
You have gathered the following research on: {{topic}}

Raw findings:
{{raw_findings}}

Now synthesize this into a coherent, well-structured report:
1. Resolve any contradictions between sources
2. Identify the 3 most important insights
3. Draw conclusions the raw data implies but doesn't state explicitly
4. Recommend concrete actions based on the findings

Output format: Professional report, suitable for executive presentation.
```
